# WorkBridge E-Labour Software

WorkBridge is a LinkedIn-style professional networking and on-demand labour booking platform for local workers and customers. This monorepo contains a Next.js frontend and an Express + MongoDB backend with OTP-based authentication and role-based experiences for workers, customers, and admins.

## Quick Start

```bash
# install deps for both workspaces
npm install

# start backend (dev)
npm run dev:backend

# start frontend (dev)
npm run dev:frontend
```

See docs/QUICKSTART.md for environment setup, .env templates, and deployment steps.
