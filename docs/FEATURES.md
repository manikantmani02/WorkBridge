# Features

- OTP-based authentication (worker/customer roles) with JWT
- Role-aware dashboards: worker feed, customer booking/search, admin overview
- Job posting and booking lifecycle (Requested → Accepted → In-Progress → Completed → Cancelled)
- Ratings and reviews (one-time per job), fraud-safe
- Location intelligence hooks (geo queries, clustering) using Mapbox
- Payments ready: Razorpay/Stripe integration points and wallet/commission model stubs
- Notifications: SMS/push hooks and console fallback
- PWA-ready frontend with responsive labour-friendly UI and Framer Motion animations
